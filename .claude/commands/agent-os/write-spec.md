# Write Specification

Create a detailed specification document from shaped requirements.

## Instructions

### Prerequisites

Ensure you have a shaped specification in `agent-os/specs/[spec-name]/requirements.md`.

### Process

1. **Read Requirements:** Load and analyze the requirements document

2. **Draft Specification:** Create `agent-os/specs/[spec-name]/spec.md` with:
   - Overview and purpose
   - Detailed feature description
   - User stories and acceptance criteria
   - Technical implementation notes
   - API contracts (if applicable)
   - Data models and schemas
   - UI/UX specifications
   - Testing requirements

3. **Check Standards:** Ensure the specification aligns with project standards in `agent-os/standards/`

4. **Review:** Present the specification for user review

### Output

Confirm the spec file is created at `agent-os/specs/[spec-name]/spec.md`.

The specification is now ready for task creation with `create-tasks`.
