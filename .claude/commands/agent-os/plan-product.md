# Plan Product

Plan and document your product's vision, mission, roadmap, and technology stack.

## Instructions

Follow this 4-phase process to create comprehensive product documentation:

### Phase 1: Gather Product Information

Ask the user about their product vision:
- What problem does this product solve?
- Who are the target users/personas?
- What are the key features and capabilities?
- What differentiates this from competitors?

Document responses in `agent-os/planning/product-concept.md`.

### Phase 2: Create Mission Document

Based on the gathered information, create a concise mission document at `agent-os/planning/mission.md` that includes:
- Product vision statement
- Core value proposition
- Target audience
- Key success metrics

### Phase 3: Create Development Roadmap

Create a phased development plan at `agent-os/planning/roadmap.md`:
- Break down features into phases
- Prioritize based on user value and dependencies
- Define MVP scope
- Outline future enhancements

### Phase 4: Establish Tech Stack

Document the technology choices at `agent-os/planning/tech-stack.md`:
- Frontend framework and tools
- Backend/API technology
- Database and storage
- Infrastructure and deployment
- Development tools and processes

## Output

After completion, confirm all planning documents have been created and provide a summary.
